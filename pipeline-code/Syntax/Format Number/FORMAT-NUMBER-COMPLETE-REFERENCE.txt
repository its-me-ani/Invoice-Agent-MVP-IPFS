CELL FORMAT NUMBER COMPLETE REFERENCE

SYNTAX STRUCTURE

Cell with formatted number:
cell:<coordinate>:v:<numeric_value>:ntvf:<format_id>

Value format definition:
valueformat:<format_id>:<pattern>

Required components:
- coordinate: Cell reference like A1, B2, C3
- numeric_value: The actual numeric value stored in the cell
- ntvf: Number text value format attribute linking cell to format definition
- format_id: Numeric identifier linking cell attribute to format pattern
- pattern: Format pattern string defining display rules

CORE PROPERTIES

ntvf attribute:
Applied to cell line with numeric value
References a valueformat definition by ID
Must match an existing valueformat definition
Syntax: ntvf:<format_id>

valueformat definition:
Must be defined if referenced by any cell
Format ID must be numeric positive integer
Pattern defines how number displays
Multiple valueformat definitions allowed
Syntax: valueformat:<format_id>:<pattern>

FORMAT PATTERN SYMBOLS

Number formatting:
# - Digit placeholder, omitted if insignificant
0 - Digit placeholder, shows 0 if no digit
, - Thousands separator
. - Decimal point

Currency:
$ - Dollar sign prefix
Other currency symbols allowed

Percentage:
% - Converts decimal to percentage (0.75 becomes 75%)

Date components:
m - Month as number (1-12)
mm - Month as two digits (01-12)
mmm - Month as short text (Jan-Dec)
mmmm - Month as full text (January-December)
d - Day as number (1-31)
dd - Day as two digits (01-31)
yy - Year as two digits (06, 23)
yyyy - Year as four digits (2006, 2023)

Time components:
h - Hour in 12-hour format (1-12)
hh - Hour padded (01-12)
m - Minute (0-59)
mm - Minute padded (00-59)
s - Second (0-59)
ss - Second padded (00-59)
AM/PM - Meridian indicator
\c - Escaped colon separator

Special formatting:
() - Parentheses for negative numbers
- - Minus sign for negative numbers

NUMBER REPRESENTATION SYSTEM

Integers and decimals:
Stored as numeric values
Examples: 1234, 1234.56, 0.75

Date values:
Stored as serial numbers representing days since epoch
Example: 38718 represents January 4, 2006
Example: 45292 represents December 15, 2023

Time values:
Stored as decimal fractions of a day
0.0 = midnight (00:00:00)
0.5 = noon (12:00:00)
0.520833 = 12:30 PM
0.521354 = 12:30:45

Percentage values:
Stored as decimal values
0.75 with pattern 0.00% displays as 75.00%
0.5 with pattern 0.00% displays as 50.00%
0.9999 with pattern 0.00% displays as 99.99%

Negative numbers:
Stored as negative values
-500.50 with pattern ($#,##0.00) displays as ($500.50)

COMPLETE PATTERN CATALOG

Basic number patterns:
#,##0 - Thousands separator, no decimals (1,234)
#,##0.00 - Thousands separator, two decimals (1,234.56)
#,##0.0000 - Thousands separator, four decimals (1,234.5678)
0 - Plain integer, no formatting (1234)

Currency patterns:
$#,##0 - Dollar sign, no cents ($1,234)
$#,##0.00 - Dollar sign with cents ($1,234.56)
($#,##0.00) - Negative in parentheses ($500.50 or ($500.50))

Percentage patterns:
0.00% - Two decimal percentage (75.00%)
0% - Integer percentage (75%)

Date patterns:
m/d/yy - Short date (1/4/06)
mm/dd/yyyy - Full date with slashes (01/04/2006)
yyyy-mm-dd - ISO date format (2006-01-04)
d-mmm-yy - Short month name (4-Jan-06)
dd-mmm-yyyy - Full month abbreviation (04-Jan-2006)
mmmm d, yyyy - Long format (January 4, 2006)

Time patterns:
h\cmm - 12-hour time (12:30)
h\cmm AM/PM - 12-hour with meridian (12:30 PM)
h\cmm\css - 12-hour with seconds (12:30:45)
hh\cmm\css - Padded hours with seconds (01:30:45)

VALIDATION RULES

Format ID requirements:
Must be numeric positive integer
Must match between ntvf and valueformat
Cannot be zero or negative
Cannot use text characters

Pattern requirements:
Cannot be empty
Must contain valid pattern symbols
Date/time patterns require proper escaping
Currency symbols placed at pattern start

Cell requirements:
Numeric values required for number formats
ntvf attribute must reference existing valueformat
Multiple cells can share same format ID
Each cell can only have one ntvf value

COMMON ERROR PATTERNS

Error: Undefined format reference
cell:A1:v:1234:ntvf:99
sheet:c:1:r:1
Problem: No valueformat:99 defined
Solution: Add valueformat:99:<pattern>

Error: Missing valueformat definition
cell:A1:v:1234.56:ntvf:1
sheet:c:1:r:1
Problem: No valueformat line exists
Solution: Add valueformat:1:#,##0.00

Error: Non-numeric format ID
cell:A1:v:1234:ntvf:abc
valueformat:abc:#,##0
Problem: Format ID must be numeric
Solution: Use numeric ID like ntvf:1

Error: Empty format pattern
cell:A1:v:1234:ntvf:1
sheet:c:1:r:1
valueformat:1:
Problem: Pattern is empty
Solution: Provide valid pattern like #,##0

Error: Duplicate ntvf attributes
cell:A1:v:1234:ntvf:1:ntvf:2
Problem: Cell has multiple ntvf values
Solution: Use only one ntvf per cell

Error: Text value with number format
cell:A1:t:Hello:ntvf:1
valueformat:1:#,##0
Problem: Text value cannot have number format
Solution: Use numeric value or remove ntvf

Error: Negative format ID
cell:A1:v:1234:ntvf:-1
valueformat:-1:#,##0
Problem: Format ID cannot be negative
Solution: Use positive integer ID

Error: Invalid pattern symbols
valueformat:1:##,##,##0
Problem: Pattern has invalid structure
Solution: Use correct pattern like #,##0

Error: Mismatched format reference
cell:A1:v:1234:ntvf:1
valueformat:2:#,##0
Problem: Cell references format 1 but only 2 exists
Solution: Match IDs between ntvf and valueformat

Error: Double percent signs
valueformat:1:0.00%%
Problem: Pattern has duplicate percent symbols
Solution: Use single percent like 0.00%
