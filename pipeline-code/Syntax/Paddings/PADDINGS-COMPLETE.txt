PADDING LAYOUT SYNTAX - COMPLETE REFERENCE

PROPERTY NAME
Cell padding using layout property with padding values

LAYOUT PROPERTY
layout:<index>:padding:<top> <right> <bottom> <left>;vertical-align:<alignment>;

SYNTAX STRUCTURE
Cell reference: cell:<cell_reference>:t:<text>:l:<layout_index>
Layout definition: layout:<index>:padding:<top> <right> <bottom> <left>;vertical-align:<alignment>;

CORE PROPERTIES
Property name: padding
Format: padding:TOP RIGHT BOTTOM LEFT;
Order: Top Right Bottom Left (clockwise from top)
Units: px (pixels)
Wildcard: * (asterisk represents default/no padding)
Reference: l:<index> in cell definition
Combination: Always paired with vertical-align property in same layout definition

PADDING VALUE ORDER
Position 1: Top padding
Position 2: Right padding
Position 3: Bottom padding
Position 4: Left padding

WILDCARD USAGE
Symbol: *
Meaning: Use default value (typically 0px or no padding)
Usage: Replace any position with * to skip that padding side
Example: padding:10px * * * (only top padding)
Example: padding:* * * 15px (only left padding)
Example: padding:* * * * (no padding on any side)

VERTICAL ALIGNMENT OPTIONS

Value: top
Effect: Aligns content to top of cell
Syntax: vertical-align:top;

Value: middle
Effect: Centers content vertically in cell
Syntax: vertical-align:middle;

Value: bottom
Effect: Aligns content to bottom of cell
Syntax: vertical-align:bottom;

Value: *
Effect: Default vertical alignment (typically top)
Syntax: vertical-align:*;

USE CASES

Use Case 1: Visual breathing room
Apply uniform padding to all cells in table for improved readability and professional appearance

Use Case 2: Text indentation
Use left padding to create indented text for hierarchical lists or nested content structures

Use Case 3: Header spacing
Apply top and bottom padding to header rows to visually separate them from data rows

Use Case 4: Button-like appearance
Use uniform padding on all sides to create clickable button-style cells with centered text

Use Case 5: Form field spacing
Apply padding to form input cells to create comfortable touch targets and visual separation

Use Case 6: Invoice line items
Use padding to space out invoice line items for clarity and professional presentation

Use Case 7: Dashboard tiles
Apply large uniform padding to dashboard metric cells for prominent display

Use Case 8: Menu items
Use left padding combined with borders to create menu-style navigation cells

Use Case 9: Content cards
Apply padding to cells containing multiline content to create card-like visual groupings

Use Case 10: Table cell spacing
Use padding instead of cell spacing to control internal cell spacing in complex table layouts

Use Case 11: Nested content hierarchy
Use increasing left padding values to show parent-child relationships in tree structures

Use Case 12: Calendar cells
Apply uniform padding to calendar date cells for consistent day cell sizing

Use Case 13: Label-value pairs
Use right padding on label cells and left padding on value cells for visual separation

Use Case 14: Icon and text combinations
Use left padding to add space between cell border and icon/text content

Use Case 15: Banner cells
Apply large top and bottom padding to create banner-style cells spanning multiple columns

PADDING SIZE RECOMMENDATIONS

Minimal: 1px to 3px
Purpose: Subtle spacing in dense layouts
Example: layout:1:padding:2px 2px 2px 2px;vertical-align:*;

Small: 5px to 8px
Purpose: Compact tables with slight breathing room
Example: layout:1:padding:5px 5px 5px 5px;vertical-align:*;

Medium: 10px to 15px
Purpose: Standard comfortable spacing for most applications
Example: layout:1:padding:12px 12px 12px 12px;vertical-align:*;

Large: 20px to 30px
Purpose: Prominent cells, buttons, dashboard tiles
Example: layout:1:padding:25px 25px 25px 25px;vertical-align:*;

Extra Large: 40px and above
Purpose: Hero sections, large banners, special emphasis
Example: layout:1:padding:40px 40px 40px 40px;vertical-align:*;

LAYOUT REFERENCE SYNTAX

Cell property: :l:<index>
Layout definition: layout:<index>:padding:VALUES;vertical-align:ALIGN;
Index range: Positive integers starting from 1
Multiple layouts: Each layout needs unique index
Reference before definition: Cell can reference layout defined later in savestr

COMMON ERRORS TO AVOID

Error 1: Missing layout value after reference
Wrong: cell:A1:t:Content:layout
Correct: cell:A1:t:Content:l:1

Error 2: Missing layout index
Wrong: cell:A1:t:Content:l:
Correct: cell:A1:t:Content:l:1

Error 3: Layout definition without cell reference
Wrong: layout:1:padding:10px * * *;vertical-align:*;
Correct: layout:1:padding:10px * * *;vertical-align:*;
         cell:A1:t:Content:l:1

Error 4: Undefined layout reference
Wrong: cell:A1:t:Content:l:99 (without layout:99 definition)
Correct: cell:A1:t:Content:l:1 + layout:1:padding:* * * *;vertical-align:*;

Error 5: Missing semicolons in layout definition
Wrong: layout:1:padding:10px * * * vertical-align:*
Correct: layout:1:padding:10px * * *;vertical-align:*;

Error 6: Wrong padding value order
Wrong: layout:1:padding:10px 15px 20px;vertical-align:*; (missing fourth value)
Correct: layout:1:padding:10px 15px 20px 25px;vertical-align:*;

Error 7: Missing vertical-align property
Wrong: layout:1:padding:10px * * *;
Correct: layout:1:padding:10px * * *;vertical-align:*;

Error 8: Using px without value
Wrong: layout:1:padding:px * * *;vertical-align:*;
Correct: layout:1:padding:10px * * *;vertical-align:*;

Error 9: Mixing different units
Wrong: layout:1:padding:10px 2em 5% 15px;vertical-align:*;
Correct: layout:1:padding:10px 20px 50px 15px;vertical-align:*;

Error 10: Missing colon separator
Wrong: cell:A1:t:Content:l1
Correct: cell:A1:t:Content:l:1

Error 11: Invalid vertical-align value
Wrong: layout:1:padding:* * * *;vertical-align:center;
Correct: layout:1:padding:* * * *;vertical-align:middle;

Error 12: Combining with undefined border
Wrong: cell:A1:t:Content:l:1:b:99 (without border:99 definition)
Correct: cell:A1:t:Content:l:1:b:1 + border:1:1px solid rgb(0,0,0)

Error 13: Combining with undefined font
Wrong: cell:A1:t:Content:l:1:f:99 (without font:99 definition)
Correct: cell:A1:t:Content:l:1:f:1 + font:1:Arial * 12pt *

Error 14: Combining with undefined color
Wrong: cell:A1:t:Content:l:1:c:99 (without color:99 definition)
Correct: cell:A1:t:Content:l:1:c:1 + color:1:rgb(255,0,0)

Error 15: Incomplete property reference chain
Wrong: cell:A1:t:Content:l:1:b:1:1
Correct: cell:A1:t:Content:l:1:b:1

RENDERING BEHAVIOR

Input: layout:1:padding:10px * * *;vertical-align:*;
Effect: Adds 10 pixels of space between cell top border and content

Input: layout:1:padding:* * * 15px;vertical-align:*;
Effect: Adds 15 pixels of space between cell left border and content

Input: layout:1:padding:20px 20px 20px 20px;vertical-align:*;
Effect: Adds 20 pixels of space on all four sides between border and content

Input: layout:1:padding:* * * *;vertical-align:middle;
Effect: No padding but centers content vertically in cell

Input: layout:1:padding:5px 10px 15px 20px;vertical-align:*;
Effect: Top 5px, Right 10px, Bottom 15px, Left 20px spacing

TECHNICAL SPECIFICATIONS

Property syntax: layout:<index>:padding:<values>;vertical-align:<align>;
Index requirement: Positive integer starting from 1
Value format: Number followed by px unit or * wildcard
Value count: Exactly 4 values required (top right bottom left)
Separator: Space character between padding values
Terminator: Semicolon after padding values and after vertical-align
Reference syntax: :l:<index> in cell definition
Multiple layouts: Each layout must have unique index
Vertical align required: Must always specify vertical-align even if using wildcard
Vertical align values: top, middle, bottom, or * (wildcard)
Units supported: px (pixels) only
Wildcard meaning: Use default or no padding for that side
Property combination: Can combine with f, cf, b, bg, c, colspan, rowspan in same cell

DATA VALIDATION RULES

Rule: Layout index must be positive integer
Rule: Padding requires exactly 4 space-separated values
Rule: Each padding value must be numeric with px unit or * wildcard
Rule: Semicolon required after padding values
Rule: Vertical-align property required in every layout definition
Rule: Vertical-align must be top, middle, bottom, or *
Rule: Semicolon required after vertical-align value
Rule: Cell reference :l:<index> must point to defined layout
Rule: Layout can be defined before or after cell reference
Rule: Multiple cells can share same layout definition
Rule: Each layout definition must have unique index
Rule: Sheet dimensions must accommodate all cells using layouts

WHEN NOT TO USE PADDING

Do not use when cell borders should directly touch content
Do not use when space constraints require maximum density
Do not use when padding would make cells too large for layout
Do not use when external cell spacing (row height/column width) is sufficient
Do not use when all cells need identical spacing (use global styles instead)
Do not use when padding causes content wrapping issues
Do not use when print layouts have strict size requirements
Do not use when exporting to formats that do not support padding
Do not use when accessibility requires content at cell edges
Do not use when padding breaks visual alignment with adjacent cells

SUMMARY

Padding layout property controls internal cell spacing using four values for top right bottom left sides. Specified in layout definitions with padding:VALUES;vertical-align:ALIGN; format. Referenced in cells using :l:INDEX syntax. Values can be pixel measurements or * wildcard for default. Always combined with vertical-align property. Compatible with all cell properties including fonts, borders, colors, alignment, and spanning. Primary use cases include buttons, forms, cards, tables, indentation, and spacing. Renders as space between cell border and content. No limit on padding size. Multiple cells can share same layout. Each layout must have unique index.
