FORMAT TEXT PROPERTIES - SOCIALCALC COMPLETE REFERENCE

SYNTAX STRUCTURE

Basic pattern for text formatting in cells:
cell:<coord>:t:<content>:tvf:<number>
valueformat:<number>:<type>

The tvf attribute (text valueformat) references a valueformat definition that controls how the content is rendered.

AVAILABLE VALUEFORMAT TYPES

text-plain
Purpose: Renders content as plain text without any formatting or HTML interpretation
When to use: Simple string display where no formatting is needed, raw text content, data that should not be interpreted as HTML
Example: cell:A1:t:Simple Text:tvf:1 with valueformat:1:text-plain

text-html
Purpose: Renders content as HTML allowing rich formatting, styling, embedded SVG graphics, and inline images
When to use: Rich text with formatting, embedded graphics, logos, icons, styled content, complex visual elements, signatures, badges
Example: cell:A1:t:<b>Bold Text</b>:tvf:1 with valueformat:1:text-html

text-link
Purpose: Renders content as clickable hyperlink
When to use: External URLs, navigation links, references, citations, downloadable resources
Example: cell:A1:t:<a href="https\c//example.com">Visit Website</a>:tvf:1 with valueformat:1:text-link

text-wiki
Purpose: Renders content using wiki markup syntax
When to use: Documentation with wiki-style formatting, rare use case
Example: Limited practical usage, text-html preferred for most cases

COLON ESCAPING RULES

In SocialCalc save format, colons are field separators and must be escaped when appearing in content.

Escape colons with backslash-c: \c

URL escaping:
Incorrect: https://example.com
Correct: https\c//example.com

CSS property escaping:
Incorrect: style="color:red;"
Correct: style="color\cred;"

Data URI escaping:
Incorrect: data:image/png;base64
Correct: data\cimage/png;base64

JavaScript protocol escaping:
Incorrect: javascript:void(0)
Correct: javascript\cvoid(0)

Multiple colons in same string:
Incorrect: http://example.com:8080/path
Correct: http\c//example.com\c8080/path

Semicolons in CSS:
Incorrect: style="color:red;background:blue;"
Correct: style="color\cred;background\cblue;"

TIME FORMATS DO NOT REQUIRE ESCAPING IN CONTENT
Only URLs, CSS, and protocol strings require colon escaping.

HTML TAGS SUPPORTED WITH TEXT-HTML

Basic formatting tags:
<b>text</b> - Bold text
<i>text</i> - Italic text
<u>text</u> - Underlined text
<strong>text</strong> - Strong emphasis
<em>text</em> - Emphasis

Typography tags:
<sup>text</sup> - Superscript
<sub>text</sub> - Subscript
<code>code</code> - Inline code
<pre>text</pre> - Preformatted text with preserved whitespace

Styling tags:
<div style="property\cvalue;">content</div> - Block container with CSS
<span style="property\cvalue;">content</span> - Inline container with CSS
<p style="property\cvalue;">content</p> - Paragraph with CSS

List tags:
<ul><li>item</li><li>item</li></ul> - Unordered list
<ol><li>item</li><li>item</li></ol> - Ordered list

Table tags:
<table><tr><td>cell</td><td>cell</td></tr></table> - Embedded table

Link tags:
<a href="url">text</a> - Hyperlink (use with text-link valueformat)

Image tags:
<img src="url" width="100" height="50" alt="description" /> - External image
<img src="data\cimage/png;base64,..." alt="icon" /> - Inline base64 image

SVG GRAPHICS WITH TEXT-HTML

SVG elements can be embedded directly in cell content when using text-html valueformat.

Basic structure:
<svg width="N" height="M">...</svg>

Common SVG elements:

Rectangle:
<rect x="0" y="0" width="100" height="50" fill="color" stroke="color" stroke-width="2" />

Circle:
<circle cx="50" cy="50" r="40" fill="color" stroke="color" stroke-width="2" />

Ellipse:
<ellipse cx="50" cy="30" rx="40" ry="20" fill="color" />

Line:
<line x1="0" y1="0" x2="100" y2="100" stroke="color" stroke-width="2" />

Polygon:
<polygon points="x1,y1 x2,y2 x3,y3" fill="color" stroke="color" />

Path:
<path d="M x y L x y Z" fill="color" stroke="color" />

Text in SVG:
<text x="50" y="50" font-family="Arial" font-size="20" fill="color" text-anchor="middle">Content</text>

Group elements:
<g>...multiple elements...</g>

Gradients:
<defs>
  <linearGradient id="grad1" x1="0%" y1="0%" x2="100%" y2="100%">
    <stop offset="0%" style="stop-color\crgb(255,255,0);stop-opacity\c1" />
    <stop offset="100%" style="stop-color\crgb(255,0,0);stop-opacity\c1" />
  </linearGradient>
</defs>
<rect width="100" height="100" fill="url(#grad1)" />

SVG attributes commonly used:
width, height - Dimensions
fill - Fill color
stroke - Stroke color
stroke-width - Stroke thickness
cx, cy - Center coordinates for circles/ellipses
rx, ry - Radius for ellipses
x, y - Position coordinates
x1, y1, x2, y2 - Line endpoints
font-family, font-size, font-weight - Text styling
text-anchor - Text alignment (start, middle, end)
alignment-baseline - Vertical alignment

XMLNS attribute for complex SVG:
<svg width="200" height="100" xmlns="http\c//www.w3.org/2000/svg">...</svg>

IMAGE EMBEDDING CAPABILITIES

External images via URL:
cell:A1:t:<img src="https\c//example.com/logo.png" width="100" height="50" alt="Logo" />:tvf:1
valueformat:1:text-html

Inline base64 images:
cell:A1:t:<img src="data\cimage/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAUA..." alt="Icon" />:tvf:1
valueformat:1:text-html

Required attributes for images:
src - Image source (URL or data URI)
width - Image width in pixels
height - Image height in pixels

Optional attributes:
alt - Alternative text description
style - CSS styling (border-radius for rounded images, etc.)

Image styling examples:
Round profile picture: style="border-radius\c50%;"
Bordered image: style="border\c2px solid black;"
Positioned image: style="margin-left\c10px;"

COMMON ERRORS TO AVOID

Missing tvf value:
Incorrect: cell:A1:t:Text:tvf
Correct: cell:A1:t:Text:tvf:1

Undefined valueformat reference:
Incorrect: cell:A1:t:Text:tvf:5 with only valueformat:1:text-html defined
Correct: cell:A1:t:Text:tvf:1 with valueformat:1:text-html defined

Unescaped colons:
Incorrect: <a href="https://example.com">Link</a>
Correct: <a href="https\c//example.com">Link</a>

Missing cell content:
Incorrect: cell:A1:tvf:1
Correct: cell:A1:t:Content:tvf:1

Wrong attribute order:
Incorrect: cell:A1:tvf:1:t:Text
Correct: cell:A1:t:Text:tvf:1

Unclosed HTML tags:
Incorrect: <b>Bold text
Correct: <b>Bold text</b>

Missing SVG dimensions:
Incorrect: <svg><circle cx="25" cy="25" r="20" /></svg>
Correct: <svg width="50" height="50"><circle cx="25" cy="25" r="20" /></svg>

Wrong valueformat type:
Incorrect: Using text-plain for HTML content
Correct: Using text-html for HTML/SVG content

WHEN TO USE TEXT-HTML FORMAT

Required for HTML tags and formatting:
Any HTML markup including bold, italic, underline, divs, spans, paragraphs

Required for SVG graphics:
All SVG elements including shapes, paths, text, gradients

Required for embedded images:
Both external URL images and base64 inline images

Required for styled content:
Any CSS styling applied via style attributes

Required for lists and tables:
HTML lists (ul, ol) and table structures

Required for special typography:
Superscript, subscript, code blocks, preformatted text

Required for rich text:
Combined formatting with multiple HTML elements

WHEN TO USE TEXT-PLAIN FORMAT

Simple text without formatting:
Plain strings that should not be interpreted as HTML

Data values:
Numbers, dates, identifiers displayed as-is

Names and labels:
Simple text labels without styling needs

Raw content:
Content that might contain HTML-like characters but should display literally

Fallback text:
Default format when no special formatting needed

WHEN TO USE TEXT-LINK FORMAT

External URLs:
Links to websites, documents, resources

Navigation:
Menu items, references, cross-references

Downloads:
Links to downloadable files

Email addresses:
Mailto links for contact information

COMPLETE SYNTAX TEMPLATE

version:1.5
cell:<coord>:t:<content>:tvf:<number>
cell:<coord>:t:<content>:tvf:<number>
sheet:c:<maxcol>:r:<maxrow>
valueformat:<number>:<type>
valueformat:<number>:<type>

Replace:
<coord> with cell coordinate like A1, B2, C3
<content> with text, HTML, or SVG content (escape colons)
<number> with sequential number 1, 2, 3...
<type> with text-plain, text-html, text-link, or text-wiki
<maxcol> with highest column number
<maxrow> with highest row number

CRITICAL SUCCESS FACTORS FOR IMAGES SVG LOGOS

SVG logos must include width and height attributes on svg element
Images must have escaped colons in URLs using \c notation
HTML content must use text-html valueformat not text-plain
All HTML tags must be properly closed
CSS in style attributes must have escaped colons
Multiple shapes can be combined in single SVG for complex logos
Text in SVG should use text-anchor middle for centering
Colors can use named colors or hex codes
Gradients require defs section with unique IDs
Base64 images are self-contained but increase file size
External images are smaller in save format but require network access
Profile images benefit from border-radius 50% for circular appearance
Signature blocks typically combine image with text cells below
Verification badges use SVG graphics for scalable quality
Brand consistency requires matching colors across all logo instances

PERFORMANCE AND SIZE CONSIDERATIONS

Plain text format: Smallest file size, fastest rendering
HTML with simple tags: Small increase in size, fast rendering
SVG graphics: Moderate size, vector scalability, fast rendering
External images: Minimal size in save format, requires loading
Base64 images: Large increase in file size, no external dependency
Complex SVG with gradients: Larger size, still performant
Multiple valueformats: Negligible overhead per format
Mixed content cells: Size depends on content complexity
