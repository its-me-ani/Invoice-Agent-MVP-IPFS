LINKS SYNTAX COMPLETE REFERENCE

PROPERTY NAME
text-link

PURPOSE
Creates clickable hyperlinks in cells that can open URLs, email clients, phone dialers, or other protocols. Links can open in the current tab or a new browser tab depending on syntax used.

SYNTAX STRUCTURE
Cell text contains display text followed by URL in angle brackets
Single angle brackets <URL> opens link in current tab
Double angle brackets <<URL>> opens link in new browser tab
URL protocol separator uses backslash-c notation: protocol\c instead of protocol:
Must include tvf property referencing valueformat definition
Must include valueformat line with text-link type

REQUIRED COMPONENTS
version:1.5
cell definition with t property containing text and URL
tvf property with valueformat reference number
sheet definition with column and row counts
valueformat definition with format number and text-link type

VALUEFORMAT SYNTAX
valueformat:N:text-link
N is the format reference number starting from 1
Must match the tvf:N reference in cell definition
Type must be exactly text-link

LINK SYNTAX PATTERNS
Current tab: DisplayText<protocol\c//url>
New tab: DisplayText<<protocol\c//url>>
Email: DisplayText<mailto\cemail@domain>
Phone: DisplayText<tel\c+1-234-5678>
FTP: DisplayText<ftp\c//server.com>

URL PROTOCOL CONVERSION
Replace colon with backslash-c in protocols
https: becomes https\c
http: becomes http\c
mailto: becomes mailto\c
tel: becomes tel\c
ftp: becomes ftp\c

COMBINATION WITH OTHER PROPERTIES
Can combine with color property using c:N reference
Can combine with font property using f:N reference
Can combine with other cell formatting
Display text shown before angle brackets can be styled
URL part in angle brackets defines link behavior

VALIDATION RULES
tvf property must reference valid valueformat number
valueformat must use text-link type
tvf reference cannot be empty or malformed
Cannot use tvf with non-existent valueformat number
Cannot have multiple tvf references on same cell
Cannot use wrong valueformat type with tvf reference
valueformat line must use format valueformat:N:text-link
Cannot reference undefined color or font numbers
URLs must use backslash-c protocol separator notation

WHEN TO USE CURRENT TAB VS NEW TAB
Current tab single brackets for internal navigation within same site
Current tab for email mailto and phone tel links that open other applications
New tab double brackets for external websites to keep current page open
New tab for documentation and reference materials
New tab for social media or third-party services
Current tab for same-domain resources and pages
New tab for API endpoints or external tools
Current tab for file downloads or FTP links
Design choice based on user experience needs
Mix both behaviors in navigation menus for optimal flow

https for secure web links
http for non-secure web links
mailto for email client activation
tel for phone dialer activation
ftp for file transfer protocol links
Custom protocols supported with backslash-c notation
Query parameters and URL fragments preserved
Authentication credentials not recommended in URLs
Relative URLs not supported must use full protocol and domain
International domain names and Unicode characters supported in display text

DISPLAY TEXT FORMATTING
Text before angle brackets shown as clickable link
Display text can differ from actual URL
Can apply font styling to display text portion
Can apply color to entire cell including link
Display text can contain spaces and special characters
URL in angle brackets not visible to user
Empty display text shows URL as fallback
Multiple words supported in display text
Emoji and Unicode supported in display text
Display text styling independent of URL
