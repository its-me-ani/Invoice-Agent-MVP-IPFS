SOCIALCALC FONT PROPERTIES - COMPLETE REFERENCE

SYNTAX STRUCTURE
font:[number]:[style] [weight] [size] [family]

REQUIRED COMPONENTS
1. Font Number: Integer identifier starting from 1
2. Style: First component after font number
3. Weight: Second component after font number
4. Size: Third component after font number
5. Family: Fourth component after font number, can include fallback chain

COMPONENT SEPARATION
Components separated by single space
No commas between style weight size family
Colons used for font number prefix only

FONT STYLE VALUES
normal - Standard upright text
italic - Slanted text style
* - Wildcard accepting any value or default

INVALID STYLES
oblique, slanted, underline, cursive, slant, roman

FONT WEIGHT VALUES
normal - Regular weight text
bold - Heavy weight text
* - Wildcard accepting any value or default

INVALID WEIGHTS
bolder, lighter, heavy, 100, 200, 300, 400, 500, 600, 700, 800, 900

FONT SIZE VALUES
Point sizes: 6pt 8pt 9pt 10pt 12pt 14pt 16pt 18pt 20pt 24pt 32pt 36pt 48pt 72pt
Pixel sizes: 8px 10px 12px 14px 16px 18px 20px 24px 32px 36px
Named sizes: small medium large x-large
Wildcard: *

SIZE UNITS MUST BE INCLUDED
pt for points
px for pixels
Named sizes without units

FONT FAMILY VALUES
Sans-serif: Arial Helvetica Verdana Tahoma sans-serif
Serif: Times New Roman Georgia Palatino Garamond serif
Monospace: Courier New Courier monospace
Display: Impact
Cursive: Comic Sans MS cursive
Generic: * (wildcard)

FONT FAMILIES WITH SPACES
Enclose in single quotes
Times New Roman becomes 'Times New Roman'
Comic Sans MS becomes 'Comic Sans MS'
Courier New becomes 'Courier New'
Palatino Linotype becomes 'Palatino Linotype'
Trebuchet MS becomes 'Trebuchet MS'

FONT FALLBACK CHAINS
Multiple families separated by commas
Arial,Helvetica,sans-serif
'Times New Roman',Times,serif
'Courier New',Courier,monospace
Verdana,Geneva,sans-serif
Georgia,serif
Tahoma,sans-serif

CELL APPLICATION
Use f: attribute in cell definition
f:[number] refers to defined font
Cell must reference existing font number
Example: cell:A1:t:Text:f:1 requires font:1:... definition

FONT DEFINITION PLACEMENT
Font definitions placed after sheet definition
Font definitions before or after cell definitions
All fonts defined before sheet close
Multiple font definitions allowed

MULTIPLE FONTS IN DOCUMENT
Each font gets unique number
font:1:normal bold 14pt Arial
font:2:italic normal 12pt Verdana
font:3:normal normal 10pt 'Courier New',monospace
Cells reference specific font numbers

COMMON ERROR PATTERNS

Error Pattern 1 Missing Font Definition
cell:A1:t:Text:f:5
No font:5 definition exists
Fix: Add font:5:normal bold 12pt Arial

Error Pattern 2 Wrong Component Order
font:1:12pt Arial bold normal
Components not in style weight size family order
Fix: font:1:normal bold 12pt Arial

Error Pattern 3 Invalid Style Value
font:1:oblique bold 12pt Arial
font:1:slanted bold 12pt Arial
Only normal italic or wildcard allowed
Fix: font:1:italic bold 12pt Arial

Error Pattern 4 Invalid Weight Value
font:1:normal bolder 12pt Arial
font:1:normal 700 12pt Arial
Only normal bold or wildcard allowed
Fix: font:1:normal bold 12pt Arial

Error Pattern 5 Missing Size Unit
font:1:normal bold 12 Arial
Size needs pt or px unit
Fix: font:1:normal bold 12pt Arial

Error Pattern 6 Wrong Font Number Reference
font:1:normal bold 12pt Arial
cell:A1:t:Text:f:2
Cell references font 2 but only font 1 defined
Fix: cell:A1:t:Text:f:1

Error Pattern 7 Missing Font Family
font:1:normal bold 12pt
Family component required
Fix: font:1:normal bold 12pt Arial

Error Pattern 8 Incomplete Definition
font:1:bold Arial
Missing style weight size
Fix: font:1:normal bold 12pt Arial

Error Pattern 9 Invalid Named Size
font:1:normal bold huge Arial
huge not valid named size
Valid: small medium large x-large
Fix: font:1:normal bold large Arial

Error Pattern 10 Unquoted Font Name With Spaces
font:1:normal bold 12pt Times New Roman
Times New Roman has spaces needs quotes
Fix: font:1:normal bold 12pt 'Times New Roman'

TECHNICAL SPECIFICATIONS

Font Number Range
Positive integers starting at 1
No maximum limit defined
Sequential numbering recommended
Gaps allowed but discouraged

Component Order Fixed
Position 1: style normal italic or wildcard
Position 2: weight normal bold or wildcard
Position 3: size with unit or named or wildcard
Position 4: family name or stack or wildcard

Space Delimiter Required
Single space between components
No commas between style weight size family
Commas only in font family fallback chain

Quote Requirements
Single quotes for names with spaces
No quotes for single word names
Quotes around entire name not each word

Fallback Chain Syntax
Comma separated family names
No spaces after commas
Generic family last in chain
Example: Arial,Helvetica,sans-serif

Multiple Font Definitions
Each font separate line
Independent numbering
No dependencies between fonts
All accessible from cells

Cell Reference Mechanism
f: attribute links cell to font
Number after f: matches font number
One font per cell
Multiple cells can share font

Color Independence
Font and color separate properties
Both can apply to same cell
Font handles typography
Color handles appearance

VALIDATION RULES

Font Number Must Exist
Every f: reference needs matching font: definition
Error if cell references undefined font number

Style Must Be Valid
Only normal italic or wildcard accepted
Any other value causes error

Weight Must Be Valid
Only normal bold or wildcard accepted
Numeric values not accepted

Size Must Have Unit
Point sizes need pt suffix
Pixel sizes need px suffix
Named sizes no suffix
Wildcard no suffix

Family Must Be Specified
At least one family name required
Can be wildcard
Empty not allowed

Component Count Check
Minimum four components required
style weight size family
Less than four causes error

Order Validation
Components in fixed order
Wrong order causes parsing error
Cannot rearrange

Quote Matching
Opening quote needs closing quote
Mismatched quotes cause error

Fallback Chain Format
Comma separated properly
No syntax errors in chain
