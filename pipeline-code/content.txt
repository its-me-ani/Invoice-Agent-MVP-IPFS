# Alignment

Alignment in the MSC format is controlled through two mechanisms:
1. **Horizontal Alignment**: Managed via `cellformat` definitions.
2. **Vertical Alignment**: Managed via `layout` definitions using the `vertical-align` property.

## Horizontal Alignment
Horizontal alignment determines how content is positioned horizontally within a cell.
- **Left**: `cellformat:1:left`
- **Center**: `cellformat:1:center`
- **Right**: `cellformat:1:right`

## Vertical Alignment
Vertical alignment determines how content is positioned vertically within a cell. It is defined in the `layout` string.
- **Top**: `layout:1:padding:* * * *;vertical-align:top;`
- **Middle**: `layout:1:padding:* * * *;vertical-align:middle;`
- **Bottom**: `layout:1:padding:* * * *;vertical-align:bottom;`

## Comprehensive Example
This example demonstrates a report table combining various alignment configurations.
- Headers are **Center** aligned horizontally and **Middle** aligned vertically.
- Text columns are **Left** aligned horizontally and **Top** aligned vertically.
- Numeric columns are **Right** aligned horizontally and **Bottom** aligned vertically.

```msc
version:1.5
cell:A1:t:Quarterly Report:cf:1:l:1:colspan:4
cell:A2:t:Department:cf:2:l:2
cell:B2:t:Q1 Revenue:cf:2:l:2
cell:C2:t:Q2 Revenue:cf:2:l:2
cell:D2:t:Growth:cf:2:l:2
cell:A3:t:Engineering:cf:3:l:3
cell:B3:v:150000:cf:4:l:4
cell:C3:v:165000:cf:4:l:4
cell:D3:v:0.10:cf:4:l:4
cell:A4:t:Marketing:cf:3:l:3
cell:B4:v:80000:cf:4:l:4
cell:C4:v:75000:cf:4:l:4
cell:D4:v:-0.06:cf:4:l:4
sheet:c:4:r:4
cellformat:1:center

```

# Borders

Borders define the visual boundaries of cells. They are crucial for separating data, highlighting key figures (like totals), and structuring the table layout.

**Syntax:**
- Definition: `border:<id>:<thickness> <style> <color>`
- Application: `cell:<coord>:...:b:<top_id>:<right_id>:<bottom_id>:<left_id>`

**Example:**
This example creates a cell with a thick solid bottom border, often used for totals.

```msc
version:1.5
cell:A1:t:Total Amount:b:1:1:2:1
sheet:c:1:r:1
border:1:1px solid rgb(200,200,200)
border:2:2px solid rgb(0,0,0)
```

# Padding

Padding controls the space between the cell content and its borders. Proper padding improves readability by preventing text from looking cramped.

**Syntax:**
- Definition: Inside `layout` string: `padding:<top> <right> <bottom> <left>;`
- Application: `cell:<coord>:...:l:<layout_id>`

**Example:**
This example adds comfortable spacing around the text.

```msc
version:1.5
cell:A1:t:Spacious Cell:l:1
sheet:c:1:r:1
layout:1:padding:10px 15px 10px 15px;vertical-align:middle;
```

# Dimensions & Merging

Dimensions control column widths, while merging allows cells to span multiple rows or columns. These are essential for creating headers, accommodating different data lengths, and organizing complex layouts.

**Syntax:**
- **Column Width**: `col:<letter>:w:<width>` (e.g., `col:A:w:150`)
- **Merging**: `colspan:<n>` and `rowspan:<n>` in the cell definition. Covered cells must be explicitly defined as empty.

**Example:**
This example sets specific column widths and merges the header across two columns.

```msc
version:1.5
col:A:w:100
col:B:w:200
cell:A1:t:Merged Header:colspan:2
cell:B1:t:
cell:A2:t:Label
cell:B2:t:Description
sheet:c:2:r:2
```

# Fonts

Fonts define the typography of the cell content, including family, size, weight, and style. They establish hierarchy (headings vs. body) and emphasis.

**Syntax:**
- Definition: `font:<id>:<style> <weight> <size> <family>`
- Application: `cell:<coord>:...:f:<font_id>`

**Example:**
This example uses a large bold font for a title.

```msc
version:1.5
cell:A1:t:Important Title:f:1
sheet:c:1:r:1
font:1:normal bold 14pt Arial,sans-serif
```

# Formulas

Formulas allow for dynamic calculations, data manipulation, and logical reasoning within the spreadsheet. SocialCalc supports a wide range of standard spreadsheet functions.

**Syntax:**
- Definition: `cell:<coord>:v:<value>:f:<formula_string>`
- Note: The `v` field usually contains the *calculated result* (or 0 if not calculated), while the `f` field contains the formula itself (without the leading `=`).

**Common Function Categories:**

1.  **Arithmetic**: Standard operators `+`, `-`, `*`, `/`, `^`.
    -   Example: `A1*B1`
2.  **Aggregate**: `SUM`, `AVERAGE`, `MIN`, `MAX`, `COUNT`, `COUNTA`.
    -   Example: `SUM(A1:A10)`
3.  **Logical**: `IF`, `AND`, `OR`, `NOT`, `TRUE`, `FALSE`.
    -   Example: `IF(A1>100,"High","Low")`
4.  **Text**: `UPPER`, `LOWER`, `LEFT`, `RIGHT`, `MID`, `LEN`, `CONCATENATE` (or `&`).
    -   Example: `A1 & " " & B1`
5.  **Date & Time**: `TODAY`, `NOW`, `DATE`, `YEAR`, `MONTH`, `DAY`.
    -   Example: `YEAR(TODAY())`
6.  **Lookup & Reference**: `VLOOKUP`, `HLOOKUP`, `MATCH`, `INDEX`, `CHOOSE`.
    -   Example: `VLOOKUP(A1,D1:E10,2,FALSE)`
7.  **Statistical**: `SUMIF`, `COUNTIF`.
    -   Example: `COUNTIF(A1:A10,">50")`

## Comprehensive Example: Sales Dashboard

**Features Used:**

# Text Formats & HTML

SocialCalc supports rich text formatting through the `valueformat` mechanism. While standard text formats exist, the most powerful feature is the ability to render **HTML content** directly within cells. This enables advanced styling, images, SVGs, and structured layouts.

**Syntax:**
- Definition: `valueformat:<id>:<format_type>`
- Application: `cell:<coord>:...:tvf:<format_id>`

**Common Format Types:**
- `text-plain`: Standard text.
- `text-html`: Renders content as HTML. **(Most Powerful)**
- `text-link`: Renders content as a clickable link.
- `text-wiki`: Renders wiki-style markup.

## HTML Capabilities (`text-html`)

Using `text-html`, you can embed:
1.  **Images**: Using `<img>` tags (supports external URLs and Base64).
2.  **SVG Graphics**: Using `<svg>` tags for scalable vector graphics (logos, icons, charts).
3.  **Rich Text**: Bold `<b>`, Italic `<i>`, Underline `<u>`, Colors `<span style="...">`.
4.  **Lists**: Bulleted `<ul>` and Numbered `<ol>` lists.
5.  **Layouts**: Mini-tables `<table>` or `<div>` structures within a single cell.

**Important Note on Escaping:**
- Colons `:` in HTML attributes (like URLs or styles) must be escaped as `\c`.
- Example: `style="color:red"` becomes `style="color\cred"`.
- Example: `https://` becomes `https\c//`.

## Comprehensive Example: Rich Media Dashboard

This example demonstrates the power of HTML in SocialCalc, featuring:
-   **SVG Logo**: A vector graphic created directly in the cell.
-   **External Image**: An image loaded via URL.
-   **Rich Text**: Styled text with colors and lists.
-   **Hyperlink**: A clickable link.

```msc
version:1.5
col:A:w:150
col:B:w:200
col:C:w:200
cell:A1:t:Rich Media Showcase:f:1:l:1:colspan:3
cell:A2:t:SVG Logo:f:2:l:2
cell:B2:t:HTML List:f:2:l:2
cell:C2:t:External Image:f:2:l:2
cell:A3:t:<svg width="100" height="100"><circle cx="50" cy="50" r="40" stroke="black" stroke-width="3" fill="red" /><text x="50" y="55" font-family="Arial" font-size="20" text-anchor="middle" fill="white">LOGO</text></svg>:tvf:1:l:3
cell:B3:t:<b>Project Status:</b><ul><li><span style="color\cgreen">Completed</span> Phase 1</li><li><span style="color\corange">In Progress</span> Phase 2</li><li><span style="color\cred">Pending</span> Phase 3</li></ul>:tvf:1:l:4
cell:C3:t:<img src="https\c//via.placeholder.com/150" alt="Placeholder" width="150" />:tvf:1:l:3

```
